# Beta 1 — original não localizado

Segundo o autor, esta foi a **primeira versão do jogo**: faixas e personagens
desenhados com formas simples, ainda sem sprites ou imagens de personagens.
Ela veio antes da Alfa inicial, quando começou a criação de sprites.

O ZIP e o código dessa Beta 1 não foram localizados no acervo nem no histórico
do repositório. Por isso esta pasta **não é executável** e não contém uma
recriação apresentada como se fosse o arquivo original. Se o código aparecer,
ele poderá ser adicionado aqui com sua proveniência.

A pasta [`../beta-2/`](../beta-2/) contém o jogo que antes estava rotulado
incorretamente como “Beta 1”; ele já possui cenários e arte completos.
