# Soldados vs Zumbis — V19

- A tela inicial abre o mapa da campanha.
- Grama é a primeira operação desbloqueada.
- Neve, Deserto e Água ficam bloqueadas até completar a anterior.
- Antes de cada operação o jogador escolhe 7 cartas.
- O catálogo da seleção é GLOBAL: todas as cartas, inclusive as aquáticas e do deserto, aparecem em qualquer fase.
- A seleção não limita o baralho pela região.
- A linha de água continua sendo uma regra de colocação no mapa aquático.
- O fluxo de campanha segue Grama → Neve → Deserto → Água.
